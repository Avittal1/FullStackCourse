# Magic Card Animation Project

A simple interactive web page featuring a styled card with entrance and continuous animations, built using HTML5 and CSS3.

## Project Structure
- `index.html` - The main structure of the page containing the magic card.
- `styles.css` - Stylesheet containing layout rules, keyframe animations, and hover effects.

## Features
- **Base Layout:** Centered card with a fixed size, rounded corners, and a clean shadow.
- **Entrance Animation:** The card smoothly fades in and scales up when the page loads.
- **Continuous Animation:** A subtle side-to-side floating effect (`floatAnimation`).
- **Hover Interaction:** Smooth background color transition when hovering over the card. *(Rotation effect coming soon)*.

## How to Open and Run the Project
1. Make sure both files (`index.html` and `styles.css`) are saved in the same folder on your computer.
2. Locate the **`index.html`** file.
3. Double-click on `index.html` to open it directly in your default web browser (Chrome, Firefox, Edge, etc.).
   - *Alternatively:* Right-click on `index.html`, select **"Open with"**, and choose your preferred web browser.
